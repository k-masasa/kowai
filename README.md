# kowai

ブラウザで遊べるホラーゲームの試作置き場。1本ずつ `games/` の下にディレクトリを分けて作っている。

## 動かし方

```bash
$ npm install
$ npm run dev
```

http://localhost:5180/ を開くと、ゲームの一覧が出る。

## ゲーム

| ディレクトリ    | 中身                                                      |
| --------------- | --------------------------------------------------------- |
| `games/ashioto` | あしおと。夜のマンションの内廊下を歩いて、207号室に帰る。 |

- 3D は three.js で描いている。
- 音は Web Audio でその場で作っていて、音のファイルは使っていない。
- 遊んだ回数などは、ブラウザの localStorage にだけ残る。どこにも送っていない。
