# kowai

ブラウザで遊べるホラーゲームの試作置き場。1本ずつ、リポの直下にディレクトリを分けて作っている。

https://k-masasa.github.io/kowai/ で遊べる。

## 動かし方

```bash
$ npm install
$ npm run dev
```

http://localhost:5180/ を開くと、ゲームの一覧が出る。

## ゲーム

| ゲーム                                                | 中身                                                   |
| ----------------------------------------------------- | ------------------------------------------------------ |
| [あしおと](https://k-masasa.github.io/kowai/ashioto/) | 夜のマンションの階段を上がって、20階の2012号室に帰る。 |

- 3D は three.js で描いている。
- 音は Web Audio でその場で作っていて、音のファイルは使っていない。
- 遊んだ回数などは、ブラウザの localStorage にだけ残る。どこにも送っていない。
