# 開発の手順

## 1. 作り

- ゲームは1本ずつ、リポ直下のディレクトリに置く。(`ashioto/` など)
- `vite.config.js` が、`index.html` を持つディレクトリをビルドの入口に集める。新しいゲームはディレクトリを作るだけで入る。
- Vite 8 (rolldown) と three.js 0.187 で作っている。
- 公開は GitHub Pages。main に push すると、`.github/workflows/pages.yml` がビルドして公開する。

## 2. 動かす / 確かめる

```bash
$ npm run dev
```

- http://localhost:5180/ で一覧が開く。port は 5180 で固定している。
- push の前に、ビルドと整形が通るのを確かめる。

```bash
$ npm run build
$ npx prettier --check .
```

## 3. あしおと

### 3.1 ファイル

| ファイル    | 中身                                                                            |
| ----------- | ------------------------------------------------------------------------------- |
| main.js     | 遊びの流れ。電車の動き、話の流れ、日数、難しさ、出来事、死に方                  |
| kit.js      | 箱・壁・床・管・屋根などを組む共通の部品と、歩ける区画                          |
| building.js | マンションとまわり (東西の階段室、工事のふさぎ、駅までの道、家、駐輪場、掲示板) |
| town.js     | 会社のある町 (ロビー、駅までの通りと店、歩道に落ちている鈴、交番)               |
| station.js  | 駅 (改札、ホーム、線路)。乗る駅と最寄り駅で使い回す                             |
| train.js    | 2両の電車と、走っている間に窓の外を流れる景色、途中の駅のホーム                 |
| lights.js   | 照明。近い照明にだけ、本物の光を割り当てる                                      |
| people.js   | 人の模型 (住人、乗客、店員)。歩く、座る、顔を消す / だんだん白くする            |
| crowd.js    | 町や電車にいる、名前の無い人たち。決まった人数を作って使い回す                  |
| figure.js   | 顔の無い人 (面無し様)。上の踊り場で探している人も、これで作る                   |
| sound.js    | 効果音。Web Audio でその場で作る                                                |
| textures.js | 壁や看板などの絵。canvas で描く                                                 |

- 場所は、離して置いている。会社の町と乗る駅は x = -1000 のあたり、マンションと最寄り駅は x = -180 から 110、走っている間の電車は (800, 0, -300)。霧とカメラの遠さ (140m) で、ほかの場所は見えない。
- 歩ける区画の名前は、マンションの中がふつうの名前 (`H3` / `C20` など)、それ以外は `@` で始まる (`@OB` ロビー、`@CS` 通り、`@CP` 乗る駅のホーム、`@T` 電車、`@HP` 最寄り駅のホーム)。マンションの区画に入ると、建物の中の扱いになる。
- 東の階段室の区画は、西の階段室と同じ名前 (`L12` / `A12` など) で、`east` の印で見分ける。

### 3.2 開発中だけの入口

`npm run dev` の時だけ、`window.__ashioto` がある。ブラウザの console から使う。

| 名前                                              | すること                                          |
| ------------------------------------------------- | ------------------------------------------------- |
| `start(level)`                                    | 難しさを決めて始める (`easy` / `normal` / `hard`) |
| `tp(x, floor, z, yaw)`                            | 指定の場所へ移る                                  |
| `look(yaw, pitch)`                                | 向きを変える                                      |
| `home()`                                          | 2012号室に入った時の流れを始める                  |
| `walker({ strange, up, mimic, watch })`           | 階段に人を出す (`watch` は、じっと見てくる人)     |
| `follower()`                                      | うしろからついてくる人を出す                      |
| `lamp()`                                          | うしろの街灯の下に人を立たせる                    |
| `lift(floor)`                                     | その階にエレベーターを着ける                      |
| `pick(nx, ny)`                                    | 画面の点に何が写っているかを返す                  |
| `S` / `building` / `figure` / `person` / `seeker` | 遊びの状態と、建物・人の中身                      |
| `crowd` / `ride`                                  | 町と電車の人たち、走る景色と途中の駅のホーム      |
| `train` / `town` / `workStation` / `homeStation`  | 電車と、町と、2つの駅                             |
| `renderer` / `scene` / `camera`                   | 描く回数や時間を測る時に使う                      |

```js
__ashioto.start('normal')
__ashioto.tp(2.15, 2, -1.05, 0)
__ashioto.walker({ strange: true })
```

### 3.3 遊んだ記録

- localStorage の `kowai.ashioto` に、`{ visits, last }` (遊んだ回数と前の結果) を残す。タイトルの一言がこれで変わる。
- 確かめるために始めると、`visits` が増える。前に値を退避しておき、終わったら戻す。

### 3.4 注意点 (作りの癖)

- 照明は330個あるが、本物の光が当たるのは目に近い10個だけ。遠い街灯などは、近づくまで暗い。
- 20階建てなので、扉・窓・照明の光る部分などは階ごとの入れ物 (`floorGroups`) に入れ、中にいる間は上下2階分、外にいる間は下の4階分だけ描く。
- 建物の奥は中の詰まった箱で、2012号室の玄関と廊下、エレベーターの昇降路だけをくり抜いてある (`boxWithout`)。奥に何かを作る時は、くり抜いてから、内向きの壁を置く。
- 雨だれなどの汚れは、透ける板を面の数 mm 手前に貼っている (`depthWrite: false`)。
- 映り込みが無い金属は、黒い板に見える。main.js で、metalness が 0.5 以上の物に、ぼんやりした部屋の景色 (`RoomEnvironment`) の映り込みを弱く付けている。新しく作った金属も、作るのが main.js のこの処理より前なら付く。
- 電車の窓ガラスと車内の金属・白い壁は、走り出して 0.4秒後に1両目の真ん中から車内を撮り (`train.capture`)、その映り込みを使う。夜の窓に、車内がうっすら映る。窓の映り込みを強くすると、外の明かりが見えなくなる。
- 車内の明かりを消す時 (`train.setLit(false)`) は、車内の映り込みも弱くする。明るい時に撮った映り込みなので、そのままだと消しても明るく見える。
- コンビニの中の白い物や品物は、暗い道から明るく見えるように、少し自分で光らせている (`emissive`)。
- 電車は中央町から港北、西原と止まり、終点の月見台に着く (`LEGS`)。途中の駅は、走る景色の中のホーム (`ride.stop`) を寄せて止める。途中の駅ではドアは開くが、降りられない (`setOpen(k, false)`)。終点では先へは行かず、ドアを閉めて車内の明かりを消す。
- 階段室は西と東の2つ。東は、西の階段室を裏返した形で作っている (`stairX`)。西の階段は、日ごとに 9 ~ 12 階のどこか (`S.cross`) から上をふさぎ (`blockStairs`)、その階の廊下を通って東の階段に移る。20階は東の階段から出て、廊下の西の端の2012号室へ向かう。部屋番号は東の端が 01。
- うしろからついてくる人と、じっと見てくる人が追いかけてくる時は、建物の中で歩いた道すじ (`S.trail`) をたどる。階段の中で相手が見えているかは、仕切り壁の向こうかどうか (`stairBlocked`) で決める。
- 乗客は電車の中 (`train.root`) に入れて、電車と一緒に動かす。途中の駅で降りたらホームに移し、ホームと一緒に流す (`attach`)。
- この Mac では、dev サーバーにファイルの変更の知らせ (fsevents) が届かず、古い中身を返し続けていた。`vite.config.js` で、0.3秒ごとに見に行く形 (`usePolling`) にしてある。ファイルを書き換えると、開いているページは読み込み直されるので、確かめている途中の状態は消える。
  - それでも古い中身が返る時は、`main.js?v=1` のようにクエリを付けると新しい中身が返る。Chrome で `/ashioto/style.css` を開き、`index.html` の script の src を `/ashioto/main.js?v=1` に書き換えて `document.write` すると、そのまま遊べる。
- Claude in Chrome から開いたタブでは、マウスのロックが取れない (`WrongDocumentError`)。ロックが効いた時の動きは、`HTMLCanvasElement.prototype.requestPointerLock` と `document.pointerLockElement` を差し替え、`pointerlockchange` を自分で投げて確かめる。

## 4. じっか

田んぼの中の古い家と、そのまわりを歩く。住んでいた人の手書きの間取りをもとに、まず歩ける形だけを作った。怖いことはまだ起きない。操作と歩き心地 (速さ、歩幅、頭の揺れ、マウスのロック) は、あしおとと同じにしている。

### 4.1 ファイル

| ファイル     | 中身                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| main.js      | 歩く処理、カメラ、日の光、場所の名前の表示、足音と風の音の切りかえ                |
| house.js     | 母屋、北の家 (1階がものおき)、東の小屋 (ふろ・洗濯機・トイレ)、南の小屋           |
| site.js      | 庭 (畑・池・ビニールハウス)、林、用水路、田んぼ、道、牛・豚小屋、遠くの家と山     |
| kit.js       | 箱・床・屋根・階段の部品と、壁を開口ごと組む部品 (見た目とぶつかる線を一緒に足す) |
| walk.js      | 歩ける所。壁は線、床は高さと足音の種類を持った四角                                |
| materials.js | マテリアルをまとめて作る                                                          |
| textures.js  | 畳・ふすま・障子・下見板・トタン・地面などの絵。canvas で描く                     |
| lamps.js     | 丸い蛍光灯と裸電球                                                                |
| lights.js    | 照明。近い照明にだけ、本物の光を割り当てる                                        |
| sound.js     | 足音 (畳・板・土・砂利などで変える) と風の音。Web Audio でその場で作る            |

- 1間 = 1.82 m で組む。母屋は x が -3.64 から 9.7、z が -5.46 から 9.1。東を南北に道 (x が 29.6 から 34) が通り、玄関は道の方を向く。
- 家の床は地面から 50 cm 上。庭からは、玄関の石段か、ろうかの東の沓脱石 (ガラス戸が1枚あいている所) から上がる。上がれる段は 45 cm まで (`walk.js` の `STEP`)。
- 床の四角は、あとに足した方が勝つ。地面 (田んぼ、敷地) を先に、家をあとに足している。
- 分からない所は仮にしている。母屋と北の家の2階 (階段はあるが、まだ上がれない)、トイレの場所、部屋の広さ。

### 4.2 開発中だけの入口

`npm run dev` の時だけ、`window.__jikka` がある。

| 名前                            | すること                                   |
| ------------------------------- | ------------------------------------------ |
| `start()`                       | マウスをロックせずに始める                 |
| `tp(x, z, yaw)`                 | 指定の場所へ移る (yaw は 0 で北、π/2 で西) |
| `look(yaw, pitch)`              | 向きを変える                               |
| `S` / `places`                  | 歩く状態と、場所の名前の四角               |
| `renderer` / `scene` / `camera` | 描く回数や時間を測る時に使う               |

- 上から見下ろす時は、`S.mode = 'paused'` にしてから `S.feet` と `S.eyeFeet` を高くし、`look(0, -1.0)` で下を向く。戻す時は `S.mode = 'play'`。
